# Spiegelmond — rules for agents

Spiegelmond is the image viewer of the Moonshine Vibecoder family (alias **IV**).
Tasks, decisions and the Definition of Done live in the MV repository
(`telnovxander/moonshine-vibecoder`): `projects/IV/PROJECT.md`, `projects/IV/tasks/IV-NN.md`,
and its `CLAUDE.md` (statuses, checkpoints, autonomy). The family standard is
`projects/MV/STANDARD.md`, localization `projects/MV/I18N.md`, style `projects/MV/BRAND.md`.

## Safety (mandatory)

**Перед любой работой с удалением файлов или изменением метаданных перечитай раздел
«Безопасность (ОБЯЗАТЕЛЬНО)» в MV/projects/IV/PROJECT.md.**

(Before any work that deletes files or changes metadata, re-read the section
"Безопасность (ОБЯЗАТЕЛЬНО)" in `projects/IV/PROJECT.md` of the MV repository. A task that breaks
any point of that section cannot go to In Review. In short: delete only to the Recycle Bin, never
permanently; metadata changes only after a preview, atomically, with an undo journal and with
the pixels unchanged; a duplicate group always keeps at least one file; tests only on files
from `testdata/`, never on real user data.)

## Layout

- `crates/iv-core` — image logic (which files are images, opening, later folder listing, EXIF,
  decoding), no Tauri and no GUI; builds and tests on any OS.
- `src-tauri` (`iv-app`, executable `iv`) — thin Tauri layer: commands, the single window
  (`tauri-plugin-single-instance`), the open dialog, the asset protocol for images.
- `src/` — React + TypeScript interface, `locales/` — interface languages.
- `testdata/` — test images, generated by `scripts/make-testdata.py`.

## Invariants (never break)

- **The user's files are never changed without an explicit command.** Opening and showing only read.
- **Tests touch only copies of `testdata/` in temporary folders** (`tempfile`), never real user
  data or fixed paths.
- **No `unwrap()`, `expect()` or `panic!` on paths that depend on the file system** (in tests
  they are fine). Errors are `IvError`: a code and the path, never a ready user text.
- **No text in components:** every string goes through `t('key')` and `locales/<lang>.json`;
  every new text goes into all languages in the same commit (`en.json` first, it is the
  reference). `src/lib/locales.test.ts` checks keys, plural forms, placeholders and hard-coded text.
  Numbers, sizes and dates only through `Intl` (`src/lib/format.ts`, `{{count, number}}` in plural
  strings); brand names (Spiegelmond, Sichel, Vollmond, Moonshine Vibecoder) are never translated.
  The information panel, the "?" help, format messages and the Vollmond tools follow the same rule.
- **Keyboard shortcuts live in one table**, `src/lib/hotkeys.json` (`done: true` when a key works);
  the "?" / F1 help reads it, key names are translated (`keys.*`: Ctrl → Strg).
- The list of shown formats lives in `iv-core/src/formats.rs`; `src/lib/formats.ts` repeats it
  for the open dialog (a test keeps them equal).
- Colours only as tokens in `src/tokens.css` (the MV palette, checked for WCAG AA by
  `src/lib/tokens.test.ts`); amber only in Vollmond. Brand assets in `assets/brand/` come from
  MV `projects/MV/brand/` unchanged; the mode icons are the ones of Halbmond.
- Windows-only code lives under `#[cfg(windows)]` and is checked by the Windows CI job.
- Dependencies: only those approved in `projects/IV/PROJECT.md`; anything else is a question to Alex.

## Commands

```
npm ci                   # interface dependencies
npm run tauri dev        # run in development mode
npm run tauri build      # installer and app (Windows: NSIS installer)
cargo test -p iv-core    # image logic tests (any OS, no GUI)
cargo test --workspace   # all Rust tests (needs the Tauri system libraries)
npm test                 # interface tests
npm run lint             # tsc --noEmit, cargo fmt --check, cargo clippy -D warnings
python3 scripts/make-testdata.py   # regenerate testdata/
scripts/make-icons.sh    # rebuild app icons from assets/brand (needs rsvg-convert)
```

Commit messages: short English with the task key, e.g. `IV-03: add folder listing`.
